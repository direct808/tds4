## Описание:

Личный pet-проект — аналог системы трекинга и маршрутизации трафика Keitaro, на микросервисной архитектуре. Система позволяет гибко управлять рекламным трафиком, настраивать правила маршрутизации, собирать и анализировать статистику в реальном времени.


Стек технологий:
- NestJS — основной фреймворк для всех микросервисов
- GraphQL — API для клиентской части и инструментов аналитики
- gRPC — коммуникация между микросервисами
- PostgreSQL — основная база данных
- Docker / Docker Compose — контейнеризация и локальная разработка
- TypeScript — основной язык разработки
